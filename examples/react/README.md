# Commonloom React Example

This example renders the shared Commonloom content with React and Vite.

## Commands

Run commands from this directory, or use `--workspace @commonloom/example-react`
from the repository root.

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run generate` compiles the shared Markdown and copies shared assets into
this example. The `dev`, `build`, and `preview` scripts run it automatically.
