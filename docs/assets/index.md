# Commonloom Assets

This folder stores Commonloom visual assets for the documentation vault and
repository-facing docs.

> [!NOTE] Storage
> PNG assets in this folder are tracked with Git LFS through `.gitattributes`.
> Keep large binary documentation assets under `docs/assets/` unless a later
> packaging decision creates a separate public asset folder.
